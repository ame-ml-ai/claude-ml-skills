## paper-to-code

Дайте Claude статью по ML (ссылку на arXiv, ID или PDF) и получите две вещи:

1. **Разбор, по которому можно учиться.** В нём есть:
   - TL;DR, проблема и основная идея;
   - ключевые уравнения с размерностями тензоров и номерами разделов;
   - пошаговый разбор;
   - упрощения и подводные камни;
   - три вопроса для самопроверки.
2. **Минимальная реализация на PyTorch.** Один `main.py`, который работает на CPU ноутбука примерно за минуту и ничего не скачивает. Внутри есть тесты (размерности, переобучение одного батча, свойство самого метода) и демо, которое печатает реальные числа.

Навык строг к честности:
- читает саму статью, а не восстанавливает её по памяти;
- помечает каждое допущение;
- никогда не утверждает, что игрушечный запуск воспроизводит результаты статьи.

Отвечает на языке пользователя, код пишет на английском.

## Установка

**claude.ai**

1. Скачайте [`skills/paper-to-code`](skills/paper-to-code) и упакуйте папку `paper-to-code` в zip.
2. Откройте **Settings → Capabilities → Skills**, нажмите **Upload skill** и выберите архив.

**Claude Code**

```bash
git clone https://github.com/ame-ml-ai/claude-ml-skills.git
cp -r claude-ml-skills/skills/paper-to-code ~/.claude/skills/
```

Перезапустите Claude Code. Навык подключится сам, когда вы пришлёте статью.

## Использование

```text
Вот статья: https://arxiv.org/abs/2106.09685
Объясни её и реализуй основную идею на PyTorch.
```

Другие режимы:
- **«кратко»** — только TL;DR, идея и уравнения;
- **«только код»** — только реализация;
- **«выложи в гитхаб»** — готовит репозиторий с README, графиком результатов и цитированием. Перед этим спрашивает название и видимость.

## Планы

- **pytorch-debugger** — пошаговый поиск ошибок размерностей, NaN и тихих багов обучения.
- **eval-builder** — проектирование и написание наборов оценки (eval) для ML-моделей.
- **kazakh-ml-glossary** — единые казахские переводы ML-терминов для объяснений и документации.
